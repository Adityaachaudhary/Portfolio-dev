## Personal Projects

### Habitly
Staying consistent with personal habits is hard when progress is invisible. Habitly keeps a simple grid of streaks that shows exactly which habits are holding and which are slipping, so staying on track becomes a daily, visible routine instead of guesswork.

Tech stack: React, TypeScript, Supabase, Node.js, Figma, Responsive Design, UI/UX

GitHub: https://github.com/Adityaachaudhary/Habitly
Live demo: https://habitly-ashen.vercel.app/

### AI Toolkit
Reading long PDFs and Excel files to find one answer is slow and repetitive. This chatbot takes an uploaded document, summarizes it, and answers questions straight from the content using a local LLM, so the answers surface in seconds instead of a manual search.

Tech stack: Python, FastAPI, LLM, RAG, React, Decoupled Architecture, Prompting Techniques

GitHub: https://github.com/Adityaachaudhary/RAG-LocalLLM

### FreeScribe
Transcribing and translating spoken dialogue usually means juggling separate tools and waiting on each step. FreeScribe runs speech recognition right in the browser and outputs clean translated text in any language instantly, so a single recording becomes usable, multilingual text without the back and forth.

Tech stack: Bootstrap, OpenAI Whisper, Web Workers, JavaScript, Responsive Design

GitHub: https://github.com/Adityaachaudhary/scribeFree
Live demo: https://scribe-free.vercel.app/

### Strengthmax

Tech stack: React, Vite, Tailwind CSS, Problem Solving, SPA, UI/UX

GitHub: https://github.com/Adityaachaudhary/Strength_Max
Live demo: https://strength-max.vercel.app/

### Workday Automation extension
Workday job applications are long and repetitive to fill out by hand. This extension reads a resume, auto-fills the required fields, and submits only after the user confirms, so each application takes minutes instead of half an hour of typing the same details over and over.

Tech stack: React, TypeScript, Groq API key, Manifest v3, Browser Extension, PDF Parser, Prompting Techniques

GitHub: https://github.com/Adityaachaudhary/workday-automation

Tech stack: TypeScript, React, Cloudflare Hono, D1 and KV, Tailwind CSS, Resend API

GitHub: https://github.com/Adityaachaudhary/Survey-Builder
